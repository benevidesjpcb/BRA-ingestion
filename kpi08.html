How to read. Each value is the average per arrival (sum of daily totals ÷ valid movements), in minutes. Additional time = observed ASMA transit − the 2024 p20 reference, grouped by ICAO+phase+range+class+runway+sector.
ASMA is an arrivals-only metric: the time from crossing an ASMA ring to landing. The source measures two rings — C40 (40 NM) and C100 (100 NM) — one row per ring per arrival. They cover different distances and are about 10 minutes apart, so each has its own reference and they are never pooled: pick the ring above. There is no departure (DSMA) counterpart in this source.
Validation. The last panel compares the reference recomputed in this repository with the kpi08 value supplied by Brazil — close bars mean the reproduction matches.
